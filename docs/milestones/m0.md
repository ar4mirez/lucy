# m0: foundation

## Goal

Lay the foundation every later milestone stands on, before lucy runs any real work: one typed API, an
event store, a deterministic policy engine, the ai-sdlc spec model, a simulation harness, the
conformance corpus harness with corpus v1, signed releases installed through mise, and lucy's own
security baseline. 37-57 PRs, about 0.9-3.1B processed tokens.

Notes per slice:

- **1, skeleton.** No product code beyond `lucy --version` and `--help`. The doc rules are a Go test
  (`internal/doccheck`), so CI enforces them from the first commit.
- **2, releases.** Mirrors berth's signed pipeline ([D7](../decisions/D7-distribution-mise.md)).
- **3, event store.** Pure-Go SQLite; events and state change in one transaction; consumer cursors
  with generation-bound acks replace firstmate's wake files.
- **4-5, API and policy.** Every API command passes the policy engine; models only request.
- **6, spec model.** TODO(LUCY-SPEC-004): read the spec's companion docs (`adapters.md`, `policy.md`,
  `autonomy.md`, `agents.md`, `metrics.md`) before vendoring; the design report mapped only spec.md
  and the schemas.
- **8, corpus.** TODO(LUCY-CORP-002): mine firstmate's safety rules and its homes' status logs and
  incidents (the four in [PRODUCT.md](../../PRODUCT.md)) into executable scenarios.

## Out of scope

Running any real task, berth, the credential gateway, harness adapters, the validation pipeline and
every viewer: all m1. Homebrew: m3.

## Exit tests

1. Signed releases install with `mise use -g github:ar4mirez/lucy` on Linux and macOS, and mise
   verifies their attestations (LUCY-REL-001 to LUCY-REL-004).
2. The vendored schemas validate the spec's own examples (LUCY-SPEC-004, LUCY-SPEC-011).
3. The policy engine refuses every privileged action in the simulation suite unless a rule allows it
   (LUCY-POL-001, LUCY-SIM-002).
4. Corpus v1 runs; red is expected, since nothing is implemented yet (LUCY-CORP-001, LUCY-CORP-002).
5. lucy's CI blocks on its own vulnerability and dependency scans (LUCY-SEC-002).
6. The STRIDE ADR is in (LUCY-SEC-003).
7. The doc-rules test is green on Linux and macOS (LUCY-REPO-002 to LUCY-REPO-005, LUCY-REPO-007).
