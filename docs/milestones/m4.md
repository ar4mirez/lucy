# m4: breadth

## Goal

Open-ended breadth, priced per item: 5-15 PRs and about 0.1-0.8B each. Items are picked one at a time
by the owner; none blocks retiring the old supervisor.

## Scope (candidates, unordered)

- More harnesses behind the adapter contract (LUCY-BRD-001).
- An Agent Substrate runner (LUCY-BRD-002), with Kubernetes RBAC and workload identity (LUCY-SEC-013).
- ai-memory as an optional provider (LUCY-BRD-003).
- Deferred spec concepts, each its own item, plus each later spec bump (LUCY-SPEC-020).
- DAST per project (LUCY-SEC-013).
- `lucy init` scaffolding this doc structure, full or lite (LUCY-BRD-004).

## Out of scope

Anything that would grow the core instead of a provider ([R1](../decisions/R1-adversarial-review.md),
P2-18).

## Exit tests

Each item states its own exit test when it is picked. The milestone has no single exit.

## Security

Follow-ups only: DAST per project; Kubernetes RBAC and workload identity with the Agent Substrate
runner.

- Which item first, decided when m3 exits.
